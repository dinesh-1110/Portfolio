## ✨ Features & Architecture

- **Dual High-Contrast Theme System**:
  - **Sandalwood / Warm Linen (`#F8F5F0`)**: Editorial, warm aesthetic paired with Dinesh's color portrait.
  - **Architectural Charcoal & Obsidian (`#0C0D0F` / `#FFFFFF`)**: High-contrast, monochromatic dark theme paired with Dinesh's high-contrast concrete portrait.
  - **1.05s Radial Liquid Wave Transition**: Hardware-accelerated circular wave originating directly from toggle coordinates using the native View Transitions API with photographic crossfade.
- **Interactive Test Execution Simulator**:
  - Live interactive dashboard simulating UI (Selenium) and API (RestSharp) automation suites with live terminal logs, step breakdowns, and metrics.
- **Interactive Resume Modal**:
  - High-fidelity PDF viewer with real-time responsive zoom controls (`Fit Width`, `100%`, `125%`, `150%`), direct native PDF download, copyable link, and tabbed ATS highlights.
- **Mobile-First Responsive Engineering**:
  - Mobile bottom navigation bar with active section indicator, edge-safe layout, compact navigation header, and touch-optimized action targets.
- **Micro-Interactions & Smooth Momentum Scroll**:
  - Integrated with **Lenis** smooth scrolling and **Framer Motion** stagger animations with `prefers-reduced-motion` compliance.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/dinesh-1110/Portfolio.git

# Navigate to project folder
cd Portfolio

# Install dependencies
npm install
```

### Development Server

```bash
npm run dev
```

Runs the application locally at `http://localhost:5173/Portfolio/`.

### Linting

```bash
npm run lint
```

Runs Oxlint across all 25+ project files (currently 0 warnings, 0 errors).

### Production Build

```bash
npm run build
```

Generates an optimized production bundle inside `dist/`.

### Deploying to GitHub Pages

```bash
npm run deploy
```

Builds and publishes the `dist/` directory to the `gh-pages` branch.
